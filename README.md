# tab-thumbnails-explorer

この拡張機能をChromeに読み込み、新しいタブを開くと、開いたままのタブをサムネイルで見渡せます。その場で検索、切り替え、再読み込み、閉じる操作ができます。

## インストール

所要時間の目安は約2分です。デスクトップ版Chrome 111以降で使えます。手元にリポジトリがある場合は、手順2から始めてください。

1. [ZIPをダウンロード](https://github.com/pexxad/tab-thumbnails-explorer/archive/refs/heads/main.zip)して展開します。
2. Chromeで `chrome://extensions` を開き、「デベロッパー モード」をオンにします。
3. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` があるフォルダを選びます。
4. Webページを開いているウィンドウで `⌘T`（Windows / Linuxでは `Ctrl+T`）を押します。タブがカードで並べば導入完了です。

## 使い方

まず **「未撮影を一括撮影」** を押すと、一覧に留まったまま、スクリーンショットがない読み込み済みのタブを1枚ずつ撮影します。途中で止めるには **「撮影を中止」** を押します。

一覧には、現在のウィンドウにあるWebタブ（HTTP・HTTPS）がタブバー順に並びます。ピン留めや休止中のタブも含みます。横幅が十分なら6列で、最初に約3行が見えます。残りは縦にスクロールします。新しいタブを開いた直後は、そのままアドレスバーに入力できます。

| 操作 | 動作 |
| --- | --- |
| 検索欄に入力 | タイトル・URLの一部で絞り込みます。 |
| カード本体をクリック | 対象タブに切り替え、一覧を開いていたタブを閉じます。 |
| `↻` | 一覧に留まったまま、そのタブを再読み込みし、共有画像（OGPなど）や説明文を取得します。 |
| `×` | 対象タブを閉じ、一覧を更新します。 |

## サムネイルが出ないとき

- **「休止中」「読み込み中」のタブ**は一括撮影の対象外です。休止中のタブはカードをクリックして開き、読み込み後に新しいタブで一覧へ戻ります。
- **撮影できないページ**では直前のプレビューを残します。画像も説明文もなければ、ファビコンとタイトルが表示されます。
- **一括撮影中にデバッグ通知バーが出たとき**は、終了すると最後の接続解除から約5秒で消えます。接続中は通知バーからも中止できます。

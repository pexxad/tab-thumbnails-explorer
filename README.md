# tab-thumbnails-explorer

開いたままのタブを、Chromeの新しいタブから見渡して整理する拡張機能です。

## 機能

| 項目 | 動作 |
|---|---|
| 一覧 | 現在のウィンドウのWebタブ（HTTP・HTTPS）をタブバー順に表示します。ピン留めや休止中のタブも含みます。 |
| レイアウト | 横幅が十分なら6列で、最初に約3行が見える高さに調整します。狭い画面では列数が減り、残りは縦スクロールで見られます。 |
| 検索 | タイトル・URLの部分一致で絞り込みます。新しいタブを開いた直後はアドレスバーへそのまま入力できます。 |
| 切り替え | カード本体を押すと対象タブに切り替わり、操作元の一覧タブが閉じます。 |
| 再読み込み | `↻` を押したタブだけ、一覧を開いたまま再読み込みします。完了後にページの共有画像（OGPなど）を取得し、画像を利用できない場合はページの説明文に切り替えます。 |
| 閉じる | `×` を押したタブを閉じます。一覧はその場で更新されます。 |
| 一括撮影 | 「未撮影を一括撮影」で、このウィンドウの読み込み済みタブのうちスクリーンショットがないものを、一覧に留まったまま1つずつ撮影します。休止中や読み込み中のタブは対象外です。 |
| サムネイル | 前面のページで本文や画像の表示を検知したら撮影し、最初に使える画像をすぐ保存します。同じページを表示している間に最大2回追加で撮影し、最後の枠は読み込み完了後に使います。読み込み表示やほぼ白紙の画像は破棄します。画像も説明文もないタブはファビコンとタイトルで見分けられます。 |

プレビューはChromeのセッション内に保存し、ブラウザを終了すると消えます。共有画像は対象ページのオリジンで、Cookieや参照元URLを付けずに取得します。別オリジンの配信元がCORSで許可していない場合は説明文を表示します。拡張機能は、閲覧中の撮影とページのメタデータの読み取りに全サイトへのアクセス権限を使います。

一括撮影にはChromeの `debugger` 権限を使います。デバッグ通知バーは最後の接続を解除してから約5秒で消えます。一覧の「撮影を中止」で停止でき、デバッグ接続中はChromeの通知バーからも停止できます。

## インストール

1. デスクトップ版Chromeで `chrome://extensions` を開く。
2. 「デベロッパー モード」をオンにする。
3. 「パッケージ化されていない拡張機能を読み込む」で、`manifest.json` のあるフォルダを選ぶ。
4. `⌘T`（Windows / Linuxでは `Ctrl+T`）で一覧を開く。

動作を試すには、いくつかのWebタブを前面に表示してから新しいタブを開きます。休止中の動作は、`chrome://discards` からテスト用タブを解放して確認できます。

サイト固有の読み込み表示は、本文や画像と同じ構造の場合に見分けられないことがあります。撮影できなかったタブは直前のプレビューを表示します。
